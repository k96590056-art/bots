# Telegram 小程序自动登录功能提案

## 一、需求概述

用户点击 Telegram 机器人键盘中的"🎮 游戏入口"按钮，打开 Telegram 小程序（Mini App），实现**自动注册/登录**功能。

**核心要求**：必须通过 Telegram 签名验证（涉及真实金钱安全）

## 二、当前现状

### 现有键盘按钮布局（保持不变）
```
第一行：🎮 游戏入口 (web_app)
第二行：💰 账户余额 | 🏅 官方入口 (web_app)
第三行：🤷 在线客服 | 🤝 招商代理
```

### 现有登录方式
- 前端：用户名 + 密码 + 验证码
- 后端：`/api/login_pc` 接口

### 现有问题
- 点击"🎮 游戏入口"打开网站后，用户需要手动登录
- 无法利用 Telegram 用户信息自动登录

### 4.2 后端控制器 - TelegramWebhookController.php

在类中添加两个方法：

```php
/**
 * Telegram Web App 自动登录接口
 * 验证 initData 签名，自动注册/登录用户
 *
 * @param Request $request
 * @return \Illuminate\Http\JsonResponse
 */
public function webappAuth(Request $request)
{
    try {
        $initData = $request->input('init_data');

        if (empty($initData)) {
            return response()->json([
                'code' => 400,
                'message' => '缺少 init_data 参数'
            ], 400);
        }

        // 验证 Telegram 签名
        $validationResult = $this->validateTelegramWebAppData($initData);

        if (!$validationResult['valid']) {
            Log::warning('Telegram WebApp 签名验证失败', [
                'error' => $validationResult['error'],
                'init_data' => substr($initData, 0, 100)
            ]);
            return response()->json([
                'code' => 401,
                'message' => '签名验证失败：' . $validationResult['error']
            ], 401);
        }

        $userData = $validationResult['user'];
        $telegramId = $userData['id'] ?? null;

        if (!$telegramId) {
            return response()->json([
                'code' => 400,
                'message' => '无法获取用户信息'
            ], 400);
        }

        // 查找或创建用户
        $user = User::where('telegram_id', $telegramId)->first();
        $isNewUser = false;
        $firstPassword = null;

        if (!$user) {
            // 自动注册用户
            $username = $userData['username'] ?? '';
            $firstName = $userData['first_name'] ?? '';
            $user = $this->registerUserFromTelegram($telegramId, $username, $firstName);

            if (!$user) {
                return response()->json([
                    'code' => 500,
                    'message' => '用户注册失败'
                ], 500);
            }

            $isNewUser = true;
            $firstPassword = $user->first_password;

            // 清空 first_password，确保只返回一次
            $user->first_password = null;
            $user->save();

            Log::info('Telegram WebApp 新用户注册', [
                'telegram_id' => $telegramId,
                'user_id' => $user->id,
                'username' => $user->username
            ]);
        }

        // 确保用户有 api_token
        if (empty($user->api_token)) {
            $user->api_token = Str::random(60);
            $user->save();
        }

        Log::info('Telegram WebApp 登录成功', [
            'telegram_id' => $telegramId,
            'user_id' => $user->id,
            'is_new_user' => $isNewUser
        ]);

        $responseData = [
            'api_token' => $user->api_token,
            'user' => [
                'id' => $user->id,
                'username' => $user->username,
                'telegram_id' => $user->telegram_id
            ],
            'is_new_user' => $isNewUser
        ];

        // 仅新用户首次返回密码
        if ($isNewUser && $firstPassword) {
            $responseData['first_password'] = $firstPassword;
        }

        return response()->json([
            'code' => 200,
            'message' => $isNewUser ? '注册成功' : '登录成功',
            'data' => $responseData
        ]);

    } catch (\Exception $e) {
        Log::error('Telegram WebApp 登录异常', [
            'error' => $e->getMessage(),
            'trace' => $e->getTraceAsString()
        ]);

        return response()->json([
            'code' => 500,
            'message' => '服务器错误'
        ], 500);
    }
}

/**
 * 验证 Telegram Web App initData 签名
 *
 * @param string $initData
 * @return array ['valid' => bool, 'user' => array|null, 'error' => string|null]
 */
protected function validateTelegramWebAppData($initData)
{
    try {
        // 获取 Bot Token
        $botToken = SystemConfig::getValue('telegram_bot_token') ?? env('TELEGRAM_BOT_TOKEN');

        if (empty($botToken)) {
            return ['valid' => false, 'user' => null, 'error' => 'Bot Token 未配置'];
        }

        // 解析 initData
        parse_str($initData, $data);

        if (!isset($data['hash'])) {
            return ['valid' => false, 'user' => null, 'error' => '缺少 hash 参数'];
        }

        $hash = $data['hash'];
        unset($data['hash']);

        // 按字母顺序排序
        ksort($data);

        // 构建数据字符串
        $dataCheckString = '';
        foreach ($data as $key => $value) {
            $dataCheckString .= $key . '=' . $value . "\n";
        }
        $dataCheckString = rtrim($dataCheckString, "\n");

        // 生成密钥：HMAC-SHA256(bot_token, "WebAppData")
        $secretKey = hash_hmac('sha256', $botToken, 'WebAppData', true);

        // 生成签名
        $calculatedHash = bin2hex(hash_hmac('sha256', $dataCheckString, $secretKey, true));

        // 验证签名
        if (!hash_equals($calculatedHash, $hash)) {
            return ['valid' => false, 'user' => null, 'error' => '签名不匹配'];
        }

        // 验证时效性（可选，24小时内有效）
        if (isset($data['auth_date'])) {
            $authDate = (int)$data['auth_date'];
            $now = time();
            if ($now - $authDate > 86400) {
                return ['valid' => false, 'user' => null, 'error' => '认证已过期'];
            }
        }

        // 解析用户信息
        $user = null;
        if (isset($data['user'])) {
            $user = json_decode($data['user'], true);
        }

        return ['valid' => true, 'user' => $user, 'error' => null];

    } catch (\Exception $e) {
        Log::error('验证 Telegram WebApp 签名异常', [
            'error' => $e->getMessage()
        ]);
        return ['valid' => false, 'user' => null, 'error' => '验证异常：' . $e->getMessage()];
    }
}
```

### 4.3 前端 API - api.js

在文件中添加一个方法：

```javascript
//引入刚才的http.js文件
import https from './http.js';

//设置个对象，就不用一个个暴露了，直接暴露对象
let apiFun = {};

/* 获取列表 */
apiFun.get = function(url,params) {
    return https.get(url, params)
}

apiFun.post = function(url,params) {
    return https.post(url, params)
}

apiFun.login = function(params) {
    let baseURLs = sessionStorage.getItem('baseURL') || '';
    if(!baseURLs){
        sessionStorage.setItem("baseURL",baseURLs)
    }
    return https.post('/api/login_pc', params)
}

apiFun.register = function(params) {
    let baseURLs = sessionStorage.getItem('baseURL') || '';
    if(!baseURLs){
        sessionStorage.setItem("baseURL",baseURLs)
    }
    return https.post('/api/register', params)
}

// 新增：Telegram Web App 自动登录
apiFun.telegramAuth = function(params) {
    return https.post('/api/telegram/webapp-auth', params)
}

//暴露出这个对象
export default apiFun;
```

### 4.4 前端入口 - App.vue

在 `created()` 方法中添加 Telegram 自动登录检测：

```javascript
created() {
    let that = this;
    var query = that.$route.query;

    that.getApp();
    that.getGameList();

    // 新增：Telegram Web App 自动登录检测
    that.checkTelegramAutoLogin();

    if (sessionStorage.getItem('token')) {
        that.openDaoTime();
        that.getUserInfo();
    }
    if (query.pid) {
        that.pid = query.pid;
        that.$router.push({ path: `/login?type=1&pid=${query.pid}` });
    }
    that.getVisitUrl();
},
```

在 `methods` 中添加新方法：

```javascript
methods: {
    // 新增：检测 Telegram 环境并自动登录
    checkTelegramAutoLogin() {
        let that = this;

        // 检测是否在 Telegram Web App 环境中
        if (window.Telegram && window.Telegram.WebApp) {
            const initData = window.Telegram.WebApp.initData;

            // 如果有 initData 且未登录，执行自动登录
            if (initData && !sessionStorage.getItem('token')) {
                console.log('检测到 Telegram 环境，执行自动登录');

                that.$apiFun.telegramAuth({ init_data: initData }).then(res => {
                    if (res.code === 200) {
                        // 保存 token
                        sessionStorage.setItem('token', res.data.api_token);
                        that.$store.commit('changToken');

                        // 获取用户信息
                        that.getUserInfo();
                        that.openDaoTime();

                        // 如果是新用户，显示密码提示
                        if (res.data.is_new_user && res.data.first_password) {
                            that.$dialog.alert({
                                title: '注册成功',
                                message: `您的账号：${res.data.user.username}\n初始密码：${res.data.first_password}\n\n请牢记此密码，后续将不再显示！`,
                                confirmButtonText: '我已记住'
                            });
                        }

                        console.log('Telegram 自动登录成功', res.data);
                    } else {
                        console.error('Telegram 自动登录失败', res.message);
                    }
                }).catch(err => {
                    console.error('Telegram 自动登录异常', err);
                });
            }
        }
    },

    // ... 其他现有方法保持不变
}
```

## 六、测试要点

1. **正常流程**：通过 Telegram 打开 Mini App 能自动登录
2. **新用户注册**：首次访问自动创建账号，显示密码弹窗
3. **老用户登录**：已有账号直接登录，不显示密码弹窗
4. **签名验证**：伪造的 initData 返回 401 错误
5. **非 Telegram 环境**：直接访问网站正常显示登录页面
6. **过期验证**：超过 24 小时的 initData 返回错误

## 七、安全说明

由于涉及真实金钱，安全验证至关重要：

1. **签名验证**：每次请求必须验证 Telegram initData 签名
2. **时效性检查**：initData 包含 `auth_date`，设置 24 小时有效期
3. **HTTPS**：确保所有通信使用 HTTPS
